# ComposeOtpField 1.0.0

The first stable release of **ComposeOtpField**, a customizable OTP input library built with Jetpack Compose.

### Features
- `OtpField` – A customizable OTP input component.
- `AdvancedOtpField` – An advanced OTP input component with additional customization.
- `OtpFieldDefaults` – Default configurations and styling options.
- Customizable appearance and input behavior.
- Built for Jetpack Compose.
- Lightweight Android library.

### Installation

Add Maven Central to your repositories:

```kotlin
repositories {
    google()
    mavenCentral()
}
```

Add the dependency:

```kotlin
dependencies {
    implementation("io.github.rationalrocket:otpfield:1.0.0")
}
```

### Requirements
- Minimum Android SDK: 23
- Jetpack Compose
